# Assets Directory

This directory contains static assets, sample images for testing, and visual icons for the CropGuard web application.

## Testing With Sample Leaf Images

You can place test leaf images (JPG, JPEG, PNG) in this folder or upload them directly via the CropGuard web interface.

Recommended test image characteristics:
- Single leaf in focus against a clean or neutral background.
- Clear natural lighting without heavy flash or blur.
- High resolution (minimum 224x224 pixels).
